# PRUEBA DE PROGRAMACIÓN WEB — AURORA STUDIOS

Quiero que construyas una página web completa para una empresa ficticia llamada **Aurora Studios**, un estudio digital especializado en diseño web, branding, experiencias interactivas y desarrollo de productos digitales.

No quiero únicamente una landing visualmente bonita. Quiero evaluar tu capacidad para diseñar, estructurar y programar una web moderna y profesional desde cero.

## OBJETIVO

Crear una web premium que parezca realizada por una agencia digital de alto nivel.

La sensación general debe ser:

* Moderna.
* Minimalista.
* Tecnológica.
* Elegante.
* Muy visual.
* Con animaciones cuidadas.
* Sin parecer una plantilla genérica.

Referencia conceptual:

Una mezcla entre una agencia creativa, un estudio tecnológico y una empresa de diseño digital premium.

---

# TECNOLOGÍAS

Utiliza:

* Astro.
* React únicamente donde sea necesario.
* TypeScript.
* Tailwind CSS.
* Framer Motion o GSAP para animaciones.

Puedes instalar librerías adicionales si aportan valor real.

La aplicación debe poder ejecutarse con:

```bash
npm install
npm run dev
```

Organiza correctamente el proyecto en componentes.

# ANIMACIONES

Quiero que las animaciones sean una parte importante de la experiencia.

Implementa:

* aparición de textos al hacer scroll,
* parallax ligero,
* animaciones de imágenes,
* transiciones suaves,
* elementos que reaccionen al cursor,
* marquee infinito,
* hover effects,
* reveal de secciones,
* números animados,
* navegación fluida.

Evita animaciones excesivas que dificulten utilizar la página.

Prioriza 60 FPS siempre que sea posible.

---

# CURSOR

En escritorio crea un cursor personalizado.

Cursor normal:

círculo pequeño.

Al pasar por proyectos:

debe crecer y mostrar:

**VIEW**

Al pasar por botones:

debe reaccionar ligeramente.

Debe desaparecer en dispositivos táctiles.

---

# RESPONSIVE

La web debe funcionar perfectamente en:

* escritorio 1920px,
* portátil,
* tablet,
* móvil.

No quiero simplemente reducir tamaños.

Las composiciones deben adaptarse correctamente.

---

# DETALLES DE UX

Implementa:

* scroll suave,
* estados hover claros,
* navegación accesible,
* focus states,
* botones interactivos,
* carga visual agradable,
* responsive navigation.

Respeta:

```css
prefers-reduced-motion
```

para usuarios que tengan las animaciones reducidas.
