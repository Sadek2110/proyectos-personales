# BRIEF — Landing Page 3D interactiva premium

Quiero crear una página web de demostración cuyo objetivo principal sea mostrar una experiencia 3D moderna, premium y visualmente impactante.

No quiero una web tradicional con simples tarjetas y animaciones fade-in. El 3D debe ser el protagonista de toda la experiencia y debe integrarse con el scroll y el contenido.

## CONCEPTO

Crear una landing page ficticia para un producto tecnológico premium llamado:

**NOVA ONE**

Producto:
Un dispositivo futurista de inteligencia artificial personal.

No es necesario que el producto exista realmente. Se debe diseñar un objeto 3D abstracto/futurista que represente el dispositivo.

Aspecto del producto:

* Forma redondeada y minimalista.
* Mezcla de cristal oscuro, metal y superficies reflectantes.
* Pequeño núcleo luminoso interior.
* Diseño elegante, similar al lenguaje visual de productos tecnológicos premium.
* Sin copiar ningún producto o marca existente.

---

# EXPERIENCIA

La página debe sentirse como una presentación interactiva de producto.

El objeto 3D permanece como protagonista mientras el usuario hace scroll.

Cada sección modifica:

* posición
* rotación
* escala
* iluminación
* cámara

del objeto 3D.

Las animaciones deben estar sincronizadas con el scroll.

NO utilizar scroll artificial.

Debe utilizarse el scroll normal del navegador.

Utilizar preferentemente:

Three.js

o

React Three Fiber si la arquitectura elegida utiliza React.

El objeto puede crearse mediante geometría procedural si no existe un modelo GLB.

Priorizar materiales PBR.

Posible setup:

Environment lighting

Area lights

Soft shadows

Metalness

Roughness

Glass / transmission

Evitar escenas excesivamente pesadas.

---

# ANIMACIÓN

Utilizar:

GSAP

ScrollTrigger

para sincronizar las animaciones con el scroll.

Las animaciones deben depender del progreso real del scroll.

Ejemplo conceptual:

scroll 0–15%
Hero

15–30%
Rotación + desplazamiento

30–50%
Exploded view

50–65%
Core

65–85%
Reconstruction

85–100%
Final product

Las transiciones deben mezclarse entre ellas y no sentirse como secciones independientes.

---

# DETALLES DE INTERACCIÓN

Añadir:

parallax muy ligero

microinteracciones en botones

cursor response sobre el objeto 3D

movimiento de cámara extremadamente sutil con el ratón

efectos de profundidad

entrada progresiva de textos

No utilizar animaciones simplemente porque sí.

Toda animación debe reforzar la sensación 3D.

Optimizar:

sombras

Reducir sombras y efectos.

Desactivar interacciones dependientes del cursor.

Mantener la experiencia visual.

---

# IMPORTANTE

Antes de programar:

1. Define la arquitectura.
2. Define cómo será el objeto 3D.
3. Define las posiciones de cámara.
4. Define una timeline completa del scroll.
5. Después implementa.

El resultado final debe estar completamente funcional.

No utilizar placeholders rotos.

No dejar secciones a medias.

No utilizar imágenes externas si no son necesarias.

Si se necesita un modelo 3D, crear una alternativa procedural directamente con Three.js para que la demo funcione inmediatamente.
